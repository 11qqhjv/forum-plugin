# 幻境网络
### 让故事不止发生在对话框里。

角色的一句话，可能成为论坛里的热帖；一次偶遇，可能被写进第二天的报纸。公开的讨论之外，还有发进邮箱的来信、漂流瓶里的心事，以及某位同人写手偷偷写下的故事。

**「幻境网络」是一款用于 SillyTavern 的沉浸式虚构网络插件。**

它可以根据你选择开放的聊天素材、角色设定与世界观，生成属于当前故事的网络内容。你既可以走进其中参与讨论，也可以作为读者，看看这个世界的人们正在聊些什么。

## 💬 社区｜故事里的互联网

提供 **论坛、贴吧、微博、小红书** 四种内容风格。

从长帖讨论、匿名闲聊，到短消息广场和生活分享，同一段故事可以在不同的平台上呈现出不同的样子。

这里不仅有帖子，也有评论、楼中楼和立场各异的网友。你可以浏览与收藏，也可以通过发帖、事件、话题发酵、挖坟、曝光等互动，让一件小事逐渐变成整个社区都在讨论的话题。

**主线里的风吹草动，也可以拥有网络上的回声。**

## ✉️ 通信｜公开讨论之外的另一面

除了社区，还提供 **私信、邮箱与角色私聊**。

有些话适合发在广场上，有些消息只适合私下送达。让故事中的公开舆论与私人往来拥有不同的表达空间，也让角色之间的联系不只停留在主聊天窗口。

## 📰 报纸｜给故事留下一期记录

把散落的故事线索与网络话题，整理成一份可以阅读的报纸。

通过新闻标题、报道、读者来信等形式，从另一种视角记录这个世界正在发生的事情。

论坛里还在争论的话题，到了报纸上，或许已经有了另一种说法。

## 🍾 漂流瓶｜主线之外的小小偶遇

以漂流瓶的形式展开互动，为故事留出一点偶然。

不必每一次相遇都推动主线，也不必每一句话都有明确目的。偶尔停下来，看看一只瓶子带来了怎样的心事与回声。

## 🔮 玄学｜把此刻的心情交给一点仪式感

提供 **22 张大阿卡纳塔罗与求签**。

可以按需让解读参考当前故事，为角色关系、剧情节点或一时的心情，添上一份带有故事感的回应。

*占卜内容用于剧情娱乐与氛围体验，不代表现实预测。*

## 📚 同人｜你也可以成为别人笔下的故事

一键刷新随机同人推荐流，无需选择分类或填写点梗。题材、类型与展示顺序随机，遇见喜欢的作品，可以展开阅读、查看留言或收藏。

包含三种创作方向：

- **梦向**：虚构同人写手的自设 × 你本人。是写手在梦你，不是你去梦写手的自设。
- **CP 向**：当前角色 × 你。
- **逆／拆 CP 向**：当前角色 × 其他人，或你 × 其他人，而不是简单把原组合的名字倒过来。

梦向设有独立的创作规则与额外审稿，**禁止拆 CP、争宠、雌竞、比较谁更配及拉踩评论**，不把喜欢写成竞争。

## 🌐 语言｜保留外语氛围，也照顾阅读体验

论坛、邮箱、报纸等网络生成内容支持参考角色对白选择语言，也可以为**当前聊天单独指定语种**。

当角色用日语交流时，网络内容也可以使用日语圈的表达，而不只是让中文网友讨论一个发生在日本的故事。

外语内容采用 **「外语原文＋简体中文翻译」** 的阅读方式：

- 正文逐段对照，中文译文紧跟对应原文。
- 评论与楼中楼各自附译，方便顺着讨论阅读。
- 标题与标签提供简短中译。
- 角色名、用户名字及固定账号名保持原样。

目标语言为中文时，不重复添加译文。

## ⚙️ 使用｜按你的故事来调整

- **读者视角**：也可以选择以读者的方式观看故事世界。
- **素材控制**：按需选择读取范围、补充世界观及读取世界书。
- **内容关联程度可调**：决定网络内容与当前故事保持怎样的距离。
- **按聊天保存**：不同聊天保留各自的网络内容与部分独立设置。
- **收藏与备份**：支持收藏，以及数据导出、导入。
- **生成渠道可选**：可使用 SillyTavern 的生成能力，也可配置独立 API。
- **兼顾手机阅读**：围绕小屏浏览、列表阅读与一键操作持续优化。

---

### 关于幻境网络

这里的帖子、新闻、来信与同人作品，均由生成模型创作，属于**故事内的虚构网络**，并非现实平台的实时内容。生成效果会受到模型能力、角色设定与上下文的影响。

它不替代主线，而是为主线之外的世界添上声音。

你在故事里生活，也有人在这个世界里，谈论你、写信给你、为你写下故事。
